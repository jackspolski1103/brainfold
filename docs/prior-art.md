# Prior art

Checked on 2026-11-12 from project pages and directory listings, not from source code. The detailed research written on 2026-11-11 is in git history.

| Project | What it is | How OIF differs |
|---|---|---|
| Krimto (Apache-2.0) | Markdown memory in git, user to team to organization hierarchy, MCP server, web dashboard | Fixed levels instead of permissions on any folder; no folder guidance |
| Fastio (commercial, hosted) | Cloud storage for agents with a remote MCP server and four permission levels | Closed and hosted |
| LucidLink (commercial) | Shared file system that added an MCP server with file locking | An enterprise drive with agents added |
| OpenViking (AGPL) | Memory, resources and skills per account and user | A heavier engine |
| Google Drive or Notion through MCP | The drive a team already has | No guidance and no permissions designed for agents |

What was not found together elsewhere: folder metadata that guides the agent, permissions kept in plain files on any folder, skills that reach every teammate's agent on their own, and a small self-hosted server.

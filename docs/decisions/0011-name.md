# 0011 Name: Brainfold

Date: 2026-11-12. Status: accepted by the author.

The project is called **Brainfold** (brain plus folders). It replaces the working name OIF everywhere: the package and command (`brainfold`), the per-folder metadata file (`.brainfold.toml`), environment variables (`BRAINFOLD_URL`, `BRAINFOLD_TOKEN`, `BRAINFOLD_DOMAIN`), the session cookie and the token prefix.

Alternatives considered: Quincho (the author did not recognize the word), Sesera, Foldmind, and Acervo, Teamlore, Engram, Lorekeep and Cofre, which were already taken on PyPI or npm.

Checked on 2026-11-12: `brainfold` was free on PyPI and on npm. Not checked: GitHub organization or repository names, domains and trademarks.

The repository and the container registry will live under the author's personal GitHub account, `jackspolski1103`.
